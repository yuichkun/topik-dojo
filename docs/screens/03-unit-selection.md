# ユニット選択画面 仕様書

## 画面概要
選択された級の学習進捗ダッシュボード兼ユニット選択画面。ユーザーの学習状況を可視化し、「続きから」の自動遷移を提供しつつ、任意のユニットへのアクセスも可能にする。

## レイアウト構成
- **ヘッダー**: 戻るボタン + 級表示（Content-Forward構成）
- **進捗エリア**: 達成率（%） + 学習済み語数 / 総語数 + プログレスバー + ストリーク
- **続きからCTA**: 次にやるべきユニットへの遷移ボタン（コバルトカード）
- **ユニットグリッド**: 全ユニットの3列グリッド（完了/現在/未着手の3状態）

## UI要素詳細

### 進捗エリア
- **達成率**: Epilogue_700Bold 48px, コバルト色。学習済み語数 ÷ 総語数
- **語数テキスト**: Manrope_400Regular 14px, 「310 / 400語」形式
- **プログレスバー**: 高さ3px, コバルト色
- **ストリーク**: 連続学習日数（0日の場合は非表示）

### 続きからCTA
- **コバルトカード**: 「次のセッション」ラベル + 「単語 XXX-YYY」+ 「開始」ボタン
- **遷移先**: 未完了の最初のユニットの学習画面（`07-learning.md`）

### ユニットグリッド
- **3列レイアウト**: 各カードにword range（例: 1-10）を表示
- **状態表示**:
  - **完了**: 白背景 + コバルト文字
  - **現在（途中）**: コバルト背景 + 白文字
  - **未着手**: グレー背景（#edeeef）+ 薄い文字（#c3c6d5）
- **タップ動作**: 任意のユニットの学習画面へ遷移

## データソース

### UNIT_PROGRESSテーブル
学習進捗の読み取り元。学習画面（07）が書き込む。

| データ | クエリ |
|---|---|
| 学習済み語数 | `getWordsLearnedByGrade` — unit_progressの(last_word_index + 1)の合計 |
| 達成率 | 学習済み語数 ÷ `getWordCountByGrade` |
| 次のユニット | `getCurrentUnit` — completed_atがnullの最初のユニット |
| ユニット状態一覧 | `getAllUnitProgressByGrade` — 全ユニットのprogress情報 |
| ストリーク | `getStreakDays` — completed_atの日付から連続日数を計算 |

## ナビゲーション

### 戻るボタン
- **動作**: 学習モード選択画面へ戻る
- **遷移先**: `02-learning-mode-selection.md`

### ユニットタップ
- **動作**: 選択したユニットの学習画面へ遷移
- **遷移先**: `07-learning.md`
