# ユニット選択画面 仕様書

## 画面概要
選択された級の学習・テスト統合ハブ。学習進捗の可視化、「続きから」の自動遷移、任意のユニットへのアクセスを提供する。ユニットタップ時のアクションシートから学習・聴解テスト・読解テストを直接選択できる。

## レイアウト構成
- **ヘッダー**: 戻るボタン + 級表示（Content-Forward構成）
- **進捗エリア**: 達成率（%） + 学習済み語数 / 総語数 + プログレスバー + ストリーク
- **続きからCTA**: 次にやるべきユニットへの遷移ボタン（コバルトカード）
- **ユニットグリッド**: 全ユニットの3列グリッド（完了/現在/未着手の3状態）
- **アクションシート**: ユニットタップ時に表示されるボトムシート

## UI要素詳細

### 進捗エリア
- **達成率**: Epilogue_700Bold 48px, コバルト色。学習済み語数 ÷ 総語数
- **語数テキスト**: Manrope_400Regular 14px, 「310 / 400語」形式
- **プログレスバー**: 高さ3px, コバルト色
- **ストリーク**: 連続学習日数（0日の場合は非表示）

### 続きからCTA
- **コバルトカード**: 「次のセッション」ラベル + 「単語 XXX-YYY」+ 「開始」ボタン
- **遷移先**: 未完了の最初のユニットの学習画面（`07-learning.md`）

### ユニットグリッド
- **3列レイアウト**: 各カードにword range（例: 1-10）を表示
- **状態表示**:
  - **完了**: 白背景 + コバルト文字
  - **現在（途中）**: コバルト背景 + 白文字
  - **未着手**: グレー背景（#edeeef）+ 薄い文字（#c3c6d5）
- **タップ動作**: アクションシートを表示

### ユニットアクションシート（ボトムシート）
ユニットタップ時に画面下部からスライドして表示。

- **ユニット情報**: 「単語 XXX-YYY」タイトル + 進捗状態（完了 / X/10語 学習済み / 未着手）
- **アクション一覧**:
  - **学習する**: book-outline アイコン、「カード形式で語彙を覚える」→ 学習画面へ
  - **聴解テスト**: headset-outline アイコン、「音声を聞いて4択で回答」→ リスニングテスト画面へ
  - **読解テスト**: document-text-outline アイコン、「ハングルを見て4択で回答」→ リーディングテスト画面へ
- **閉じ方**: 背景タップまたはAndroidバックボタン

## データソース

### UNIT_PROGRESSテーブル
学習進捗の読み取り元。学習画面（07）が書き込む。

| データ | クエリ |
|---|---|
| 学習済み語数 | `getWordsLearnedByGrade` — unit_progressの(last_word_index + 1)の合計 |
| 達成率 | 学習済み語数 ÷ `getWordCountByGrade` |
| 次のユニット | `getCurrentUnit` — completed_atがnullの最初のユニット |
| ユニット状態一覧 | `getAllUnitProgressByGrade` — 全ユニットのprogress情報 |
| ストリーク | `getStreakDays` — completed_atの日付から連続日数を計算 |

## ナビゲーション

### 戻るボタン
- **動作**: 学習モード選択画面へ戻る
- **遷移先**: `02-learning-mode-selection.md`

### アクションシートからの遷移
- **学習する**: `07-learning.md`（学習画面）
- **聴解テスト**: `08-listening-test.md`（リスニングテスト画面）
- **読解テスト**: `09-reading-test.md`（リーディングテスト画面）

## 設計意図
ユーザーのメンタルモデルが「ユニット中心」であることに基づき、ユニット選択→アクション選択の1段階でアクセスできる構成にしている。テストモード選択とテストユニット選択を独立画面にせず、アクションシートに統合することでナビゲーション深度を削減。
